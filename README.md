# Hand Particle Explosion

A hand-tracking particle experiment using OpenCV and MediaPipe.

This project detects your hand through a webcam and controls thousands of particles in real time.  
When you close your hand into a fist, the particles explode outward.

## Introduction
This project's idea, concept, direction, testing was done by me.
But the implementation support was provided with AI assistance.
It worked on surface go 4 too so Almost every computer in this world can download and use this code.

## Concept

This started as a small experiment:  
what if a hand gesture could control a field of particles?

The project may later become the base technology for a particle-style avatar or Vtuber system.

## Features

- Real-time webcam input
- Hand tracking with MediaPipe
- Particle animation with OpenCV and NumPy
- Fist gesture detection
- Particle explosion effect
- Camera rotation and mirror controls
